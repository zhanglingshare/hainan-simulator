# 海南岛产业决策风洞 · HIN-1.0 科研协议

研究状态：**可运行、可复现的条件性社会计算研究原型**。不是已完成因果识别的博士实证研究，不是经专业软件验证的SEM或SmartPLS结果，不是海南2030年的官方预测。

发布日期：2026-11-16。项目独立在 /industry/，原海南岛×新加坡2035项目完整保留。

## 1. 研究问题与估计对象

- RQ1 结构演化：海南省2020—2025三次产业增加值结构如何变化，哪些现象只是相对份额变化？估计对象为**已公布组成比例、现价部门差额、Jensen-Shannon组成差异**。目前仅属描述分析。
- RQ2 开放与留存：外贸增长、生产性服务采购和岛内增加值之间如何关联？缺实际采购边与供应商增加值率时，本地留存的识别区间有多宽？
- RQ3 网络韧性：候选产业关系断裂后，有向网络的可达节点和示意暴露如何变化？现有网络全部是研究假设，不能映射经济损失。
- RQ4 机制对抗：同样的用户部门名义增速，换用恒定、衰减回归、兑现滞后三种演化结构后，条件分布与中位数如何变化？
- RQ5 反证优先：什么新数据足以区分贸易、投资、制造、服务和农户收入的竞争机制？

## 2. 可核验数据与统计口径

### 2025年度事实

海南省统计局2025年度公报：GDP 8108.85亿元，第一产业增加值1642.55亿元，第二产业1463.86亿元，第三产业5002.44亿元，全部为2025**现价**水平。GDP实际同比+4.0%，第二产业实际同比+1.0%，建筑业实际同比−10.4%，规上工业实际同比+9.9%，固定资产投资（不含农户）同比−16.5%。货物进出口金额同比−0.7%，服务进出口金额同比+22.1%，游客总花费同比+10.5%。

原件：https://stats.hainan.gov.cn/tjj/tjgb/fzgb/2023_88252/202602/t20260226_4032927.html

### 2026年近期事实

- 2026年1—8月规上工业增加值实际同比−6.2%，货物进出口金额同比+55.2%，固定资产投资同比−10.3%。均为同一累计窗口。海南省统计局原件：https://stats.hainan.gov.cn/tjj/ywdt/xwfb/202609/t20260918_4149645.html
- 2026年前三季度GDP 5812.55亿元、不变价实际同比+1.2%。来源标明海南省统计局的中国经济信息网转载，因正式原文暂未获取，在本项目中按**B级转载待原件复核**标记：https://www.cei.cn/defaultsite/s/article/2026/10/30/4b4ff607-9d914745-01a1-8b8b5a47-08d2_home.html?columnId=4028c7ca-37115425-0137-115c411b-1128&referCode=dqbghaifx

### 六年历史

2020—2025各年**初始统计公报**摘录：2020 GDP 5532.39亿元，2021 6475.20，2022 6818.22，2023 7551.18，2024 7935.69，2025 8108.85。各年的三产业数值及逐一来源在 model.js 的 ANNUAL、SOURCES 中。由于不同年份初始公报并非同次统一历史修订版，**不得把此序列宣称为最终修订且严格可比的平衡面板**。其间的现价差额不是实际GDP增速，也不是因果贡献。

三条严禁混用的口径：**GDP现价总量 ≠ 实际增速**；**规上工业增加值 ≠ 第二产业GDP（含建筑业）**；**进出口总额、游客花费 ≠ GDP增加值或企业利润**。2026年前三季度不能与2025全年总量直接求增速。

## 4. 可复现模型

### 4.1 部门条件演化

2025各部门现价增加值 Y[s,2025] 为真实起点。未来条件路径使用：

Y[s,t] = Y[s,t−1] × (1 + g[s,t] / 100)

GDP[t] = Y[第一产业,t] + Y[第二产业,t] + Y[第三产业,t]

其中 g[s,t] = 用户直接设定的名义年增速 + 未标定的演示随机扰动 − 2027/2028年明确设定的冲击百分点。**没有从贸易、投资或网络节点自动推导GDP增量**。

研究者默认示意名义年增速依次为第一产业3%、第二产业4%、第三产业4.5%。这些不是历史回归系数。研究者同时定义三种竞争机制：恒定增速；向默认增速每年以0.7倍缩小偏离的回归机制；2026保持中性、2027才改变条件的滞后机制。0.7与滞后一年都尚未实证标定。

相同随机种子、相同年度冲击随机序列、相同2025基准用于基准世界与变更世界，即共同随机数对照。未来每年三部门抽取正态扰动，固定种子可复现。P10、P50、P90是**模型内随机轨迹的条件分位数**，并非现实风险概率、置信区间、贝叶斯后验。跨三种机制的中位差异应单独报告为结构不确定性。

### 4.2 部分识别

设100单位假设服务采购支出，本地采购比例 s，岛内供应商增加值率 v，均在[0,1]：

- 本地采购支出 = 100s
- 岛外采购支出 = 100(1−s)
- 本地服务增加值 = 100sv
- 本地中间投入 = 100s(1−v)
- 三部分支出守恒：本地增加值 + 本地中间投入 + 岛外采购 = 100。

由于真实 s 与 v 均未被本项目观测，**识别集合是[0,100]单位**；固定假设 v 时也仅可得到[0,100v]。滑杆里的点值不应当乘第三产业GDP来猜测真实流失。

要收紧识别边界：匿名企业采购金额与采购类别、供应商实际服务地和结算地、增加值率、重复计量排除、企业分行业抽样覆盖及拒访偏差评估。

### 4.3 假设有向网络

8个节点：口岸、制造、专业服务、旅游、人才、农业、加工冷链、居民收入。13条研究候选有向边全部标记为 H，**并无真实企业交易权重**。

三轮传播示例，按每个出发节点的出度均分单位冲击：

x[t+1,j] = γ × Σ(i→j) x[t,i] / 出度(i)

E[j] = x[0,j] + x[1,j] + x[2,j] + x[3,j]

γ∈[0,0.8]是未标定的传播示意系数，E为无量纲暴露。切断候选边只能改变网络可达性和暴露，**不能改变GDP轨迹**，这是测试强制约束。

真实SNA准入需要主体ID、边的现实含义（交易、人员流动、物流、资金或制度连接）、观察期、金额/频率边权、抽样漏边率、可替代路径和跨期验证。

## 5. 研究反证与竞争机制

| 观察到的现象 | 至少一种竞争解释 | 优先收集的数据 |
|---|---|---|
| 外贸增长，制造业承压 | 贸易总额与增加值统计对象不同；产业分工改变 | 货物加工环节、服务采购、分行业增加值 |
| 规上工业增长，投资下降 | 存量产能释放、设备检修周期、建设时滞 | 真实投产时间、产能利用率、分行业价格 |
| 游客花费增长 | 采购或结算外流、成本和利润变化 | 游客支出结构、商户利润、员工工资 |
| 农业产量增长 | 加工、储运、回款瓶颈和农户议价变化 | 品类价格、损耗、冷链覆盖、付款账期 |

每种解释都应说明什么证据可能将其推翻，避免用图表寻找事先喜欢的答案。

## 6. 智能模型准入门

- 真实投入产出模型：必须有海南部门间交易矩阵、价格基期、进口/岛外漏出与部门分类一致性，才可估计Leontief逆及产业乘数。
- 真实PLS/SEM：必须有合规采样的真实受访者、问卷量表和潜变量测量结构、载荷、信度、HTMT/VIF、同源偏差、子样本稳健性，并与专业软件逐项核对。
- ABM：需要可核实的主体行为约束、产业进入退出、工资招聘、跨区采购与价格行为；没有微观证据时仅可作教学演示。
- 因果分析：必须定义处理组、反事实单位、处理时点、外生识别假设和样本外/安慰剂检验。现有省级六年数据不足以建立政策因果结论。

## 7. 产品与测试

独立入口：/industry/。五层体验：真实信号 → 候选产业关系 → 双世界条件推演与部分识别 → 竞争解释及证据准入 → 可复现个人档案。

测试执行：node --check industry/model.js；node --check industry/app.js；node --test industry/tests/*.test.cjs。

重要测试契约：年度三部门相加等于GDP；同随机种子/同参数结果一致；采购100单位严格守恒；断开假设网络边不改变GDP；修改假设本地采购比例不改变GDP；所有模型内分位单调；未来路径机制分歧独立于随机区间；真实问卷计数为0；因果识别状态为false。
